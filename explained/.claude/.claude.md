# .claude/

Settings for **Claude Code** (the AI assistant) when it works in this project. Not part of the app and not committed: `.gitignore` lists `.claude/settings.local.json`.

Claude Code also reads instructions from outside this folder:

- `CLAUDE.md` at the project root (committed): how work is done in this project.
- `~/.claude/CLAUDE.md` and `~/.claude/rules/*.md` in your home folder: your rules for every project.
- `~/.claude/agents/`: the three reviewer agents (security, senior engineer, UI/UX) run after each feature.
