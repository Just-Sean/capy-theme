# .claude/

Settings for **Claude Code** (the AI assistant) when it works in this project. It isn't part of the app and isn't committed.

The only file here is `settings.local.json`: this machine's own permission settings for Claude Code. It's git-ignored (`.gitignore` lists it), so it never leaves your computer and isn't explained file by file.

Claude Code also follows the project's committed `CLAUDE.md` at the repo root (how work is done here).
