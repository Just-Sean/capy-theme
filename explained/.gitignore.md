# .gitignore

**What it is:** the list of files git never commits.

**What's in it:**

- **Tool output:** `.venv/`, `__pycache__/`, compiled `*.pyc`, `.pytest_cache/`, `.ruff_cache/`, `.coverage`, `htmlcov/`, and `dist/` (built packages).
- **The demo's local data:** `demo/db.sqlite3` (its database) and `demo/media/` (uploaded images and fonts).
- **The demo's Tailwind files:** `demo/.django_tailwind_cli/` (the downloaded Tailwind program) and `demo/static/css/tailwind.css` (the built stylesheet).
- **Local Claude Code settings:** `.claude/settings.local.json`.
