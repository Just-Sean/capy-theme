# .pre-commit-config.yaml

**What it is:** the checks that run automatically on every `git commit`, using the **pre-commit** tool. Set up once per clone with `uv run pre-commit install`. If a check fails, the commit is stopped.

**The checks:**

1. **gitleaks:** blocks a commit that contains a password, key or token. It's pinned to an exact commit (v8.30.1), because tags can be moved. It only scans what's being committed; the README has commands that scan everything.
2. **ruff check:** lint (likely bugs, unused imports, insecure patterns via the `S` rules).
3. **ruff format --check:** consistent formatting.

Both ruff hooks use the project's own ruff from `uv.lock`, so the version matches CI. `--force-exclude` keeps ruff skipping migrations.

**Never bypass it** with `git commit --no-verify`. That's also refused in your Claude settings.
