# CHANGELOG.md

**What it is:** release notes, newest first. There's a section per version (0.1.0 to 0.7.0) and an **Unreleased** section at the top for changes since 0.7.0, which will become the 1.0.0 notes.

**Who it's for:** anyone upgrading. Each entry says what changed and anything a project must do about it, like a renamed field or changed HTML.

**When you'd touch it:** each change adds a line under Unreleased. At release time, Unreleased is renamed to the version number (issue #64, the v1.0.0 release).
