# demo/tailwind/daisyui-theme.mjs

**What it is:** daisyUI 5's theme plugin file (same version, about 46 KB, MIT). It's what makes `@plugin "daisyui/theme" { ... }` blocks work: custom themes defined in CSS. capy-theme's `/theme/daisyui-theme.css` download produces blocks in that format, and this file is what a project uses to compile them into its own Tailwind build. Third-party file; don't edit.
