# demo/tailwind/daisyui.mjs

**What it is:** daisyUI 5's main plugin file (version 5.7.50, about 350 KB, MIT license). It's a copy of daisyUI's published standalone file, not written here; never edit it. It defines every daisyUI component (`btn`, `card`, `alert`...) and the built-in themes.

**Updating daisyUI:** replace this file and `daisyui-theme.mjs` with the new release's files, then follow "Updating daisyUI" in `docs/development.md`. That includes regenerating `builtin_themes.json` and the Components view's CSS.
