# docs/PLAN.md

**What it is:** the build plan the whole project followed. It's split into 9 phases (0 Setup to 8 "Advanced and 1.0") and 66 small steps. Each step is a GitHub issue, and each phase ended with a tagged release (v0.1.0 to v0.7.0; v1.0.0 is next).

**Sections:**

- how to work through it
- setting up GitHub
- the demo site and Components view
- how the module works
- the phases
- every step in detail

The notes at the top record the big revisions:

- the editor moved earlier
- capy-theme exposes artifacts instead of doing email, manifests and link previews itself
- the Components view replaced a showcase page

**When you'd use it:** to see what was planned versus built, or what's left (Phase 8's release step, issue #64).
