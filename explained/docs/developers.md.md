# docs/developers.md

**Covers:** what a developer using the theme from their own code needs.

- **every CSS variable the theme stylesheet defines:**
  - daisyUI's own (always set)
  - capy-theme's extras: fonts, type scale, focus color, logo heights, backgrounds
- how the light/dark values are switched
- a short guide to the JSON API and the downloads, pointing to `artifacts.md` for detail

**Who it's for:** someone writing CSS, a React/Vue front end, a mobile app or another Django module that should match the theme.
