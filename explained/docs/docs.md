| File | For |
| --- | --- |
| `themes.md`, `editor.md`, `colors-and-css.md`, `fonts.md`, `images.md`, `artifacts.md` | Site operators and project developers: how each feature works |
| `developers.md` | Developers using the theme from their own code |
| `development.md` | Working on capy-theme itself |
| `PLAN.md` | The build plan: phases, steps and their issues |
| `DECISIONS.md` | Why things were built the way they were |
