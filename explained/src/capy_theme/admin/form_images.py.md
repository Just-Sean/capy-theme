# src/capy_theme/admin/form_images.py

**What it is:** the form's image choices.

- **Per slot and mode:** a dropdown of this theme's uploaded images for that slot. This covers the six logos, the icon, the sharing image and both backgrounds.
- **Header logo heights:** desktop and phone.
- **The icon's background color and padding.**

Choosing an image only changes the draft. It's used once published.
