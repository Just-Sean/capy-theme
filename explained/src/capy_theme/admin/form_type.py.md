# src/capy_theme/admin/form_type.py

**What it is:** the form's font and type scale fields.

- **Fonts:** a choice per role (body, headings, mono, display) from the font library, or "Default".
- **Type scale:** number fields for base size, heading scale, line height and heading weight, with the limits and steps from `type_settings.json`.

Blank means "keep the project's own".
