# src/capy_theme/colors/colors.json

**What it is:** data about daisyUI's 20 colors, read by `names.py`.

- **`groups`:** how the editor and admin group them:
  - **Basic:** primary, secondary, accent, neutral, background, text on background
  - **Advanced:** info, success, warning, error, the two darker backgrounds
  - **Expert:** the text color on each colored element
- **`labels`:** friendlier names where daisyUI's differ, e.g. `base-100` is "Background".
- **`with_content`:** which colors have a matching text ("-content") color.
