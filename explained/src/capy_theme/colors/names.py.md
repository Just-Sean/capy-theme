# src/capy_theme/colors/names.py

**What it is:** the 20 color names, from `colors.json`.

- `COLOR_GROUPS`, `COLOR_NAMES` (all 20 in order), `SCHEMES` (light and dark), `COLOR_LABELS`, `WITH_CONTENT`.
- **`label(name)`:** the display name, e.g. "Primary text".
- **`overrides(settings, scheme)`:** the colors a theme sets for one mode.
