# src/capy_theme/css/shape.json

**What it is:** data for the shape settings, read by `shape.py`.

**Sizes** (each has a variable, unit, min, max, step, label and help):

| Setting | Range | Arrow step |
| --- | --- | --- |
| Small corner radius | 0–2 rem | 0.125 |
| Field corner radius | 0–2 rem | 0.125 |
| Box corner radius | 0–3 rem | 0.125 |
| Small control size | 0.125–0.5 rem | 0.0625 |
| Field size | 0.125–0.5 rem | 0.0625 |
| Border width | 0–4 px | 0.5 |

**Effects:** depth (3D shading) and noise (grain), each with a label and help.

The editor and admin show these labels and help texts. The JSON settings schema has the same limits.
