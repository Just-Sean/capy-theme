# src/capy_theme/css/type_settings.json

**What it is:** data for the type scale settings, read by `typography.py`.

| Setting | Range | Arrow step |
| --- | --- | --- |
| Base text size | 14–24 px | 0.5 |
| Heading scale | 1.05–1.6× | 0.01 |
| Line height | 1.1–2.2 | 0.05 |
| Heading weight | 100–900 | 100 |

Each also has a label and help text. The base size's minimum of 14 px keeps text readable.
