# src/capy_theme/fonts/subsets.json

**What it is:** the character sets fonts can be trimmed to, as CSS Unicode ranges:

- Latin
- Latin Extended
- Cyrillic (and extended)
- Greek (and extended)
- Vietnamese

The ranges come from Google Fonts (Apache 2.0; credited in THIRD_PARTY_NOTICES). Used by `uploads.py` for trimming, and as the `unicode-range` in `@font-face`.
