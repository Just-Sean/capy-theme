# src/capy_theme/fonts/system_stacks.json

**What it is:** the system font stacks: `font-family` lists of fonts already on visitors' devices, so **nothing is downloaded**.

- System sans, System serif and System mono.
- Ten styles from Modern Font Stacks (CC0): Transitional, Old Style, Humanist, Geometric Humanist, Neo-Grotesque, Rounded, Slab Serif, Didone, Monospace Code and Industrial.

Migration 0008 added them to the library, using its own frozen copy, as migrations must.
