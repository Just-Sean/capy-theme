# src/capy_theme/images/icons.json

**What it is:** data for `icons.py`:

- **`files`:** the seven icon files, each with its pixel size and what it's for (browser tab, iPhone home screen, Android icon, maskable, monochrome).
- **`settings`:** the labels and help for the icon's two settings:
  - **Icon background:** a hex color, or blank for transparent.
  - **Icon padding:** 0–25% on each side.
