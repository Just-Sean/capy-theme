# src/capy_theme/images/slots.py

**What it is:** the image slots, read from `slots.json`.

- `SLOTS`: slot → label, max bytes, max pixels, help.
- `SLOT_MODES`: the modes each slot can have its own image for (email and print logos and the sharing image only have light).
- `NO_SVG`
- `SLOT_CHOICES`, used by the model field.
- `MODES`: light and dark.
