# src/capy_theme/static/capy_theme/admin/

Scripts and styles used on capy-theme's admin pages:

- `color_input.js`: links each color text box to its color picker.
- `tabs.js` and `tabs.css`: the tabs on the theme edit page.
- `images.css`: the image slots and the Media list's previews.
- `save_publish.css`: the theme page's Save and publish area and the theme list's row buttons.
