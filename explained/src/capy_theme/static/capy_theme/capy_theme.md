# src/capy_theme/static/capy_theme/

| Folder | What |
| --- | --- |
| `admin/` | One small script for the admin's color inputs |
| `editor/` | The live editor: its main script, the panel's CSS, the Components view's stylesheet, and one script per panel section in `controls/` |
| `fonts/` | The 30 bundled open-license fonts, one folder each |

The editor's files are only loaded for staff who can edit themes. Visitors download none of them.
