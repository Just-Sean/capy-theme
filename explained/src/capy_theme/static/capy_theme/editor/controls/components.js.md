# src/capy_theme/static/capy_theme/editor/controls/components.js

The **Components view** button.

- **Show all components** opens the `components/` page in an iframe beside the panel.
- Each time the preview changes, the draft's CSS is put into the iframe, so the samples update as you edit.
- Unsaved image choices are passed in the iframe's address, so it reloads to show them.
- It follows "See it as a visitor".
- Escape or **Close components** closes it.
