# src/capy_theme/static/capy_theme/editor/controls/image-choices.js

The **Images** choices part:

- which uploaded image each slot uses, light and dark: the six logos, icon, sharing image, both backgrounds
- the header logo heights (desktop and phone)
- the icon's background and padding

Choices are saved with Save draft. Backgrounds preview on the page straight away.

Logos and the tab icon don't preview on the page itself yet (they show in the Components view). That's the next planned feature.
