# src/capy_theme/static/capy_theme/editor/controls/visitor.js

**See it as a visitor.** It's a switch at the top of the panel. While it's on, the page (and the Components view) shows the **published** theme visitors get instead of the draft, and the draft controls are hidden.

**Options:** mode, an offered theme, or a date (to check schedules).

It also shows a summary of what's set up for visitors. Turning it off brings the draft back. Nothing is saved.
