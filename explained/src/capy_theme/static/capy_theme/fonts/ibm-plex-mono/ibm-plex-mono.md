# src/capy_theme/static/capy_theme/fonts/ibm-plex-mono/

**IBM Plex Mono**, a bundled monospace font (Fontsource package version 5.3.0, SIL Open Font License 1.1).

**Files:**

- `LICENSE`
- `ibm-plex-mono-latin-400-italic.woff2`
- `ibm-plex-mono-latin-400-normal.woff2`
- `ibm-plex-mono-latin-700-normal.woff2`

The WOFF2 files are the Latin character set in these weights and styles: 400 normal, 700 normal, 400 italic. `LICENSE` is the font's license text, which must travel with the files.

**Fallback stack:** `ui-monospace, SFMono-Regular, Menlo, Consolas, "Liberation Mono", monospace`.

Generated by `scripts/fetch_curated_fonts.py`; don't edit by hand. `manage.py capy_theme_add_fonts` copies the files into a project's media storage and adds the font to the library.
