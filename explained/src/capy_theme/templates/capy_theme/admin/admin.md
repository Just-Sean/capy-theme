# src/capy_theme/templates/capy_theme/admin/

Templates for the admin pages capy-theme adds (Revisions, Restore, Import theme, Import Google font) or extends (the theme and font lists and the theme edit page, to add buttons). `save_publish.html` is the theme page's Save and publish area, included in the edit page. They extend Django's own admin templates, so they look like the rest of the admin.
