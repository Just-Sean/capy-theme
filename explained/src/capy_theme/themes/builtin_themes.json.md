# src/capy_theme/themes/builtin_themes.json

**What it is:** data, **generated, don't edit by hand**. It holds all 35 of daisyUI 5.7.50's built-in themes. For each:

- whether it's light or dark
- every value: the 20 colors (`--color-primary`, ...), radii, sizes, border, depth and noise

**Made by:** `scripts/generate_builtin_themes.py`, from the published daisyUI package. Regenerate it when updating daisyUI. Read by `catalog.py`.
